## ドキュメントサイトの版トラック

このサイトはライブラリ SemVer とは別の **docs トラック**も持ちます（npm 版は上げません）。

| トラック | 例 | 内容 |
|----------|-----|------|
| ライブラリ | `0.13.0` | npm の `@b4moss/hyogen-md` |
| ドキュメントサイト | `0.10.0-docs.8` | Nuxt サイト、Playground 統合、コンテンツ |

`0.10.0-docs.*` 以降のライブラリ機能（**0.11.0**〜**0.13.0**）は、サイトコンテンツ更新とともに反映されます。

## 現行ライブラリ版
