# TOC 専用ヘルパ

ページ内見出しをパースし、TOC（目次）を Markdown として生成する。

## 方針

- **専用ヘルパ**として提供する（ビルトイン関数は導入しない）
- 出力は **Markdown**（ネストしたリスト + アンカーリンク）。HTML 化は対象外
- 複数の TOC を同一ページに置ける（各 TOC は独立に全文から生成）

## 構文

次の **3 形式すべて** で `toc(N)` を書ける（等価）。

| 形式 | 例 |
|------|-----|
| HTML コメント（ショートハンド） | `<!--@@ toc(3) @@-->` |
| インラインショートハンド | `@@ toc(3) @@` |
| hyogen ブロック | `@hg toc(3) @hg` |

展開後、該当ディレクティブは TOC の Markdown に **置換** される（[pipeline.md](./pipeline.md)）。

## 引数

| 項目 | 内容 |
|------|------|
| `N` | **整数 1〜6**。対象とする見出しの **最大レベル**（例: `toc(3)` → h1〜h3） |
| 省略時 | **h6 まで**（= 全レベル） |
| 不正値 | **エラー**（`HyogenError`）で停止。負数・小数・0・7 以上・非数値 |

## 見出しの抽出

### 対象

- **ATX 見出し**（`#` 形式）
- **Setext 見出し**（`===` → h1、`---` → h2）
- 引数 `N` で指定した最大レベル以内の見出しのみ

### 抽出元

extend / include / component 展開後、式評価（`{{ }}`）完了後の **最終 Markdown** から抽出する。

| ソース | 含めるか |
|--------|----------|
| 現在のページ本文 | ✓ |
| `extend` / layout 側 | ✓ |
| `include` 展開先 | ✓ |
| `component` 展開先 | ✓ |
| `if` / `each` で条件により消えた見出し | ✗（最終出力に残ったもののみ） |

### TOC の記述位置

**文書全体** を対象とする。TOC ディレクティブの位置に関係なく、上記抽出元の全見出しを含める。

### 除外領域

次の領域 **内部** の見出し行は対象外とする。

- フェンス付きコードブロック（`` ``` `` / `~~~`）
- hyogen ブロック（`@hg` … `@endhg` / `@@` … `@@`）
- HTML コメント（`<!-- ... -->`）

## 出力形式

- **ネストした Markdown リスト**（見出しレベルに応じてインデント）
- 各項目に **アンカーリンク** を付ける（`[テキスト](#anchor)`）
- 見出しテキストは **プレーンテキスト**（`**bold**` 等の Markdown 装飾記号を除去）
- 該当見出しが 0 件のときは **空文字**（何も出力しない）

### アンカー ID

1. 見出しに明示 ID がある場合（例: `## Title {#my-id}`）→ **`{#my-id}` を優先**
2. それ以外 → **GitHub 互換**の自動生成
   - 小文字化
   - 空白 → ハイフン
   - 記号除去
   - 同一文書内で重複時は `-1`, `-2`, … を付与

### 出力例

input（抜粋）:

```markdown
# Page Title

<!--@@ toc(3) @@-->

## Section A

### Sub A-1

## Section B
```

output（抜粋）:

```markdown
# Page Title

- [Page Title](#page-title)
- [Section A](#section-a)
  - [Sub A-1](#sub-a-1)
- [Section B](#section-b)

## Section A
...
```

## パイプライン

[pipeline.md](./pipeline.md) のファイル1本の処理順において、次の位置で実行する。

1. …（front matter 〜 `{{ }}` 評価まで）
2. **`toc` ヘルパの展開**（step 6 の直後）
3. hyogen コメントの strip（オプション）
4. front matter の strip（デフォルト）

つまり `include` / `extend` / `if` / `each` / `component` / `{{ }}` がすべて完了した **後**、hyogen コメント除去の **前** に TOC を生成する。

## エラー

| 状況 | 挙動 |
|------|------|
| 引数が整数 1〜6 以外 | **エラー**（中断） |
| 該当見出し 0 件 | 空文字（警告なし） |
